# L2: Causal discovery and driver attribution (agent report; citations verified via publisher, Crossref, arXiv or PyPI unless noted)

## 1. PCMCI / PCMCI+ (Tigramite)
- **What it does:** finds lagged links of the form "X at lag τ drives Y". The PC step trims each variable's candidate parents. The MCI step then tests each link while conditioning on both variables' pasts, which controls for autocorrelation. PCMCI+ also finds same-month (lag 0) links.
- **Citations:**
  - Runge et al. 2019, Sci. Adv. 5:eaau4996, doi:10.1126/sciadv.aau4996.
  - Runge 2020, UAI/PMLR 124, arXiv:2003.03685.
  - Reviews: Runge et al. 2019, Nat. Commun. 10:2553, doi:10.1038/s41467-019-10105-3; Runge et al. 2023, Nat. Rev. Earth Environ. 4:487, doi:10.1038/s43017-023-00431-y.
  - Krich et al. 2020, Biogeosciences 17:1033, doi:10.5194/bg-17-1033-2020. They applied PCMCI to global NDVI plus climate data and warn that non-stationarity produces false links.
- **Library:** `tigramite` 5.2.10.1 (Jan 2026), GPL-3.0, Python ≥3.10. Use ParCorr.
- **Output:** for example, "GLDAS SM → MODIS NDVI, lag 1 month, partial r = 0.42, p < 0.01".
- **Pitfalls:**
  - Work on deseasonalized anomalies, and detrend them.
  - Use 3–5 variables and τmax ≤ 3–6.
  - About 300 months (MODIS) or 130 (SMAP) is enough for linear tests; nonlinear tests are too weak at that length.
  - Assumes no hidden confounders. Apply an FDR correction.
- **Feasibility:** High. About 30 lines of code and a few seconds per region.

## 2. Granger causality (teaching contrast)
- McGraw & Barnes 2018, J. Climate 31:3289, doi:10.1175/JCLI-D-17-0334.1. Variables with memory make plain lagged regression overstate links.
- **Library:** `statsmodels`.
- **Output:** a "naive vs memory-aware" toggle.
- **Feasibility:** Very high.

## 3. Convergent cross mapping (CCM)
- **Citations:**
  - Sugihara et al. 2012, Science 338:496, doi:10.1126/science.1227079.
  - Ye et al. 2015, Sci. Rep., doi:10.1038/srep14750.
  - Pitfall: Cobey & Baskerville 2016, PLOS ONE, doi:10.1371/journal.pone.0169050. Shared seasonality can make CCM report spurious links.
- **Library:** `pyEDM` 2.5.7. **Academic/non-profit licence only.**
- **Feasibility:** Medium. It is fragile on about 300 noisy months.

## 4. SHAP attribution of trend to drivers
- **Citations:**
  - Lundberg & Lee 2017, NeurIPS, arXiv:1705.07874.
  - Liu et al. 2023, Remote Sensing 15:3531, doi:10.3390/rs15143531 (attributing kNDVI change; the percentages were seen in a snippet only).
- **Library:** `shap` 0.54.1 (MIT), with xgboost or scikit-learn.
- **Output:** for example, "of +0.012 NDVI per decade: SM 45%, precip 30%, T2M 15%, unexplained 10%".
- **Pitfalls:**
  - It attributes the model's predictions, which is not causation.
  - Correlated drivers split the credit between them.
  - Use time-blocked cross-validation.
- **Feasibility:** High.

## 5. Dominance analysis / Shapley R²
- Budescu 1993, Psych. Bull. 114:542, doi:10.1037/0033-2909.114.3.542.
- **Library:** `dominance-analysis` (MIT), or hand-code it (2^k regressions).
- **Output:** for example, "Precip explains 38% of NDVI variance, SM 22%, T2M 9%".
- **Feasibility:** Very high. It is linear and measures variance shares, not causation.

## 6. LLM + causal discovery (an emerging research area)
- **Verified papers:**
  - Cohrs, Varando, Diaz, Sitokonstantinou & Camps-Valls 2024, "LLMs for Constraint-Based Causal Discovery", arXiv:2406.07378. Using an LLM as the independence oracle gave highly variable results.
  - Wang et al. 2025, "Causal-Copilot", arXiv:2504.13263. An LLM agent that runs more than 20 causal-discovery algorithms.
  - arXiv:2510.13417 (2025). Causal chains generated by LLMs on climate topics are mostly associative pattern matching.
- **Not found:** any peer-reviewed work that combines an LLM with PCMCI on NASA Earth-observation data. Present this as our novelty and say "to our knowledge".
- **Safe design:**
  1. Qwen proposes a graph of the links and lags it expects.
  2. Tigramite tests that graph (`link_assumptions`).
  3. The UI marks each link as "LLM expected / data confirmed / data did not support".
  4. Qwen writes the explanation only from the returned numbers.

## How to present the results honestly
- Say "statistically supported lagged dependency, consistent with…", never "X causes Y". Show the assumptions.
- Put pairwise correlation (many arrows) next to PCMCI (few arrows) to show the confounder story.
- Show n, lag, effect size and FDR p for each link. Grey out links when n is below about 100.
- Robustness badge: re-run on each half of the record and with τmax ±1.
- Name what the model can't see: CO2 fertilization (Zhu et al. 2016, NCC 6:791, doi:10.1038/nclimate3004, about 70% of greening), land use and irrigation.
- The causal graph explains anomalies. Present the drivers of the trend separately (dominance or SHAP).
